Sniffer 0.1.0 is the first packaged release of the Windows command-line memory scanner and editor.

## Highlights

- Search every running process with a matching executable name.
- Scan signed and unsigned integers, floating-point values, and strings.
- Narrow results with repeated filters and `eq`, `ne`, `lt`, or `gt` predicates.
- Maintain multiple named search contexts in one interactive session.
- Pick, remove, clear, and undo changes to the active result set.
- Replace matching values once or continuously rewrite them with `repeat`.
- Split memory regions into chunks and distribute scans across worker threads.

## Download and run

1. Download `sniffer-windows-x64.exe` and `sniffer-windows-x64.exe.sha256` from the release assets.
2. Optionally verify the download in PowerShell:

   ```powershell
   Get-FileHash .\sniffer-windows-x64.exe -Algorithm SHA256
   ```

   Compare the reported hash with the value in `sniffer-windows-x64.exe.sha256`.

3. Install the [latest supported Microsoft Visual C++ Redistributable for x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) if the required runtime is not already installed.
4. Open an elevated terminal and start an interactive session:

   ```powershell
   .\sniffer-windows-x64.exe interactive -pname "PROCESS_NAME.exe"
   ```

A typical search and replacement session looks like this:

```text
find 100 type i32
filter 75 type i32
list
set 999
```

## Known limitations

- The packaged executable supports 64-bit Windows only.
- Interactive mode is the supported workflow; legacy one-shot actions remain incomplete.
- Results and named contexts are kept only for the current session.
- String replacement is performed in place and cannot grow the original allocation.
- The `threads` command currently clamps positive values to one, although the initial worker count uses the system processor count.
- Protected processes and software using anti-tamper mechanisms may remain inaccessible.

> [!WARNING]
> Sniffer reads and writes memory in other processes. Use it only with software you own or are authorized to inspect. Writing an invalid value can corrupt data or crash the target process.
